## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Website lead form

The site stays a static export (output: "export"). The inspection card posts JSON to Command Center /api/leads/intake. Set NEXT_PUBLIC_LEAD_INTAKE_URL and NEXT_PUBLIC_PW_INTAKE_SITE_KEY from .env.example. The site key is a public, rotatable form key — not the CRM login and not PW_INTAKE_SECRET.

Local preview: run Command Center on 127.0.0.1:3010 and this app on localhost:3000, with the intake URL pointed at the local Command Center.
